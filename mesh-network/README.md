# Mesh Networking Module

## Objective
Enable nearby Android devices to exchange emergency messages without internet access.

## Responsibilities
- Discover nearby devices.
- Establish and manage connections.
- Send and receive emergency messages.
- Forward messages between connected devices.
- Prevent duplicate message forwarding.

## Planned Technology
- Kotlin
- Android
- Google Nearby Connections API
- Cluster strategy for connecting multiple devices

## Status
Planning and implementation in progress.
